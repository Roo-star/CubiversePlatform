# Cubiverse Platform

[Open CubiEngine Studio](https://roo-star.github.io/CubiversePlatform/)

Cubiverse opens in CubiEngine Studio. The public build includes the workbench, local example, CubiGames, Play Twist, and the source catalog. AI conversion and asset generation run through the local Studio application.

GitHub Pages can publish this build from the root of the `main` branch. [Third-party notices](THIRD-PARTY-NOTICES.txt) and upstream source licenses are included.
